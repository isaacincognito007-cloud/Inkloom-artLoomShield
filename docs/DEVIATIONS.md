# LOOMSHIELD — CUMULATIVE RECORD OF ARCHITECTURAL DEVIATIONS

This document provides a cumulative record of all architectural deviations, scope refinements, and design evolutions from the original Round 1 plan through Round 3 closure, along with comprehensive engineering justifications.

---

## 1. CUMULATIVE DEVIATIONS REGISTER

| # | Architecture Domain | Round 1 Plan | Round 3 Implementation | Detailed Engineering Justification |
| :---: | :--- | :--- | :--- | :--- |
| **D1** | **Identity & Access Governance** | Client-side persona dropdown switching between Creator, Reviewer, and Administrator personas without verification. | HMAC-signed 8-hour bearer tokens (`POST /api/demo/login`), persistent submitter identity tracking, and separation of duties blocking submitter self-approval. | Client-side persona selectors cannot enforce real compliance. True governance requires that the actor who submitted an audit cannot approve it (`test_self_approval_blocked_and_different_reviewer_succeeds`). |
| **D2** | **Certificate Tamper Evidence** | Public blockchain or external ledger timestamping for compliance certificate anchoring. | Local Ed25519 asymmetric cryptography (RFC 8032) + canonical JSON (RFC 8785) with public key publishing and an in-database revocation ledger. | External ledgers introduce recurring financial costs, third-party network latency, and privacy leakage of document hashes for zero benefit in single-tenant deployments. Ed25519 signatures provide mathematical non-repudiation against the brand's published public key (`test_certificate_sign_and_verify_round_trip`). |
| **D3** | **Client IP & Reverse Proxy Handling** | Naive `request.client.host` socket address extraction. | Configurable right-to-left proxy hop parsing (`LOOMSHIELD_TRUSTED_PROXY_HOPS`, default: 1) and provider header gating (`CF-Connecting-IP`, `X-Real-IP`). | Cloud hosting providers (Render, Cloudflare) append proxy IPs to `X-Forwarded-For`. Trusting leftmost headers enables spoofing attacks to bypass rate limits (`test_h8_get_client_ip_render_proxy_anti_spoofing`). |
| **D4** | **Image Memory & Pixel Cap** | 25 Megapixel ceiling with unbuffered Pillow decode. | 12.0 Megapixel ceiling ($12,000,000$ pixels) enforced on headers before decode, with shared RGBA decode across analyzers. | Empirical memory profiling showed 4000x4000 images consume 158-204 MB peak RSS delta during decompression, exceeding the 150 MB cloud memory budget. The 12 MP cap guarantees sub-150 MB footprint (`test_g2_image_cap_12mp_accepted_and_12mp_plus_1px_rejected`). |
| **D5** | **File Upload Size Limits** | Reading entire request bodies into memory before validating size. | Chunked reading aborting immediately at 5 MB + 1 byte with HTTP 413 / 400 errors. | Prevents memory exhaustion attacks from maliciously inflated multipart uploads (`test_f2_chunked_upload_aborts_at_5mb_plus_1_byte_on_6mb_body`). |
| **D6** | **Visual Contrast & Text Detection** | Claimed optical character recognition (OCR) inside raster banner images. | Contrast measured exclusively for genuine SVG `<text>` elements; raster text marked transparently as Not Checked. Logo located via user box, SVG marker, or multi-scale NCC template match. | Python-based OCR introduces massive dependencies, slow execution, and frequent false positives. Honest compliance reporting requires stating true limits rather than producing false passes (`test_c5_svg_with_low_contrast_text_flagged_with_measured_ratio`). |
| **D7** | **Presets for Commercial Brands** | Bundling proprietary guidelines for companies like Apple, Stripe, and Nike. | Declared, not built. Replaced by a documented declarative preset schema in `docs/ROADMAP.md`. | Distributing third-party proprietary guidelines creates intellectual property and trademark liability. Presets should be loaded via isolated user-managed templates. |
| **D8** | **100 MB Streaming Uploads** | Direct ingestion of 100 MB files in standard request lifecycle. | Declared, not built. Retained 5 MB chunked limit; streaming architecture sketched in `docs/ROADMAP.md`. | 5 MB covers over 99% of marketing copy and vector banner assets. Supporting 100 MB streaming requires asynchronous background queue infrastructure to avoid thread blocking. |
| **D9** | **Threaded Inline Comments** | Free-form collaborative inline commenting on arbitrary text ranges. | Declared, not built. Focused on structured finding-level decisions (`accept`, `modify`, `dismiss`) with mandatory justifications and workflow logs. | Unstructured comment threads add significant UI clutter without contributing to the auditable cryptographic compliance chain. Structured decisions provide superior accountability. |
| **D10** | **Brand Vault Bulk Archive Import** | Ad-hoc ZIP / JSON archive file upload in the UI. | Declared, not built. RESTful CRUD endpoints with database migrations and seeders; import archive format specified in `docs/ROADMAP.md`. | Unvalidated bulk archive imports frequently cause schema drift and accidental guideline corruption. Programmatic REST endpoints provide deterministic versioning. |
