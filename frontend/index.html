About LoomShield & roadmap

Architecture overview, verified system capabilities, and upcoming engineering roadmap.

What LoomShield does

LoomShield is a brand-governance workspace that inspects marketing copy, digital documentation, and visual assets against approved organisational guidelines before publication. Every audit scores six distinct check areas:

1. Tone and Voice
Detects alarmist urgency, panic-inducing phrasing, and tone violations.
2. Terminology (Preferred words)
Enforces approved product names, brand capitalization, and prohibited terms.
3. Messaging
Ensures automated features are framed with requisite human oversight.
4. Promotional Claims
Substantiates numerical claims against approved facts using TF-IDF cosine retrieval.
5. Colours and logo
Inspects raster/SVG hex swatches and logo clear space using CIE Delta-E tolerance.
6. Accessibility
WCAG 2.1 AA contrast math, heading hierarchy, alt-text, and Flesch reading ease.

Verified System Capabilities (Verified in Code & Tests)

112 / 112 Tests Passed

Every item below is backed by running automated tests in the repository test suite:

  • Guided "New Audit" Setup: 5-question wizard dynamically generating isolated, tailor-made compliance checks with 22 validated rule-set fragments.
  • Server-Enforced Roles & Permissions: Least-privilege server enforcement (Content Creator, Reviewer, Brand Administrator) with CAS concurrency protection. Client role header override is strictly isolated to demo mode.
  • Honest Processing Architecture: Honest labels distinguishing Hosted verification engine vs Local processing with zero third-party AI APIs.
  • Atomic Finding Corrections & Lock: Compare-and-swap concurrency guards on finding decisions; approved audits are permanently locked against drift.
  • Per-IP Rate Limiting & Reverse Proxy Security: Sliding-window rate limiter with reverse proxy hop resolution (trusted Vercel edge header, multi-hop XFF), global request ceilings, and bounded memory tracking.
  • Multi-Format Ingestion: Local extraction and page/paragraph mapping across 8 formats: .pdf, .docx, .md, .html, .txt, .svg, .png, and .jpg.
